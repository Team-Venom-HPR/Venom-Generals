# Team Venom General

A responsive, static landing page that acts as the central entry point for Team Venom's three digital divisions.

## Included links
- Viper AI: https://hughston-cyber.github.io/Viper-AI/index.html
- Media Department: https://hughston-cyber.github.io/HPR-Team-Venom-Media-Department/
- Rider Management: https://hughston-cyber.github.io/Team-Venom-Rider-Management-System/#

## Files
- `index.html` — page structure and destination links
- `styles.css` — visual design and responsive layout
- `script.js` — smooth in-page navigation
- `assets/venom-mark.svg` — simple matching brand mark

## Publish with GitHub Pages
1. Create a GitHub repository for the General landing page.
2. Upload the contents of this folder to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

No build step or package installation is required.
